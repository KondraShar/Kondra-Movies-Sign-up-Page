## Features

- Full-height hero section with a cinema background image
- Custom branding using the **Norse Bold** font
- Sign-up form with fields for name, email, phone number, and password
- Client-side **password match validation** — form submission is blocked if passwords don't match
- Phone number input with regex pattern validation (`+43 664 1234567` format)
- Minimum password length of 8 characters
- Interactive button with hover and active states

1. Clone the repository:

git clone https://github.com/KondraShar/Kondra-Movies-Sign-up-Page.git

2. Open ⁠index.html⁠ in your browser.
